gully-rack-logo.png — official logo (white + blue artwork on a black canvas, 1536×1024).

The file is used unmodified. src/components/common/Logo.jsx frames the artwork area with
CSS and blends the black canvas into the surface behind it, so the logo must only be
placed on dark backgrounds (navbar, mobile menu header, footer).

If you later get a transparent PNG/SVG, update SRC, FILE and FRAME in Logo.jsx.
